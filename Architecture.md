# Architecture

## Frontend

### 1. Spec

- **Language**
  - TypeScript

- **Runtime / Package Manager**
  - Bun

- **Frontend Library**
  - React

- **Build Tool**
  - Vite

- **UI**
  - Tailwind CSS
  - shadcn/ui

- **Theme System**
  - Support:
    - Light theme
    - Dark theme
  - Allow users to switch themes manually
  - Support system theme detection based on device/browser preference
  - Store the user's selected theme for future visits
  - All components, charts, tables, forms, dialogs, and dashboards must support both themes consistently

- **State Management**
  - TanStack Query for server state
  - Zustand for local/global application state if needed

- **Form Management**
  - React Hook Form
  - Zod for form validation

- **API Communication**
  - REST API
  - Use the OpenAPI specification generated by the backend
  - Use `@hey-api/openapi-ts` to compile the OpenAPI specification into a TypeScript REST API client
  - Automatically generate:
    - API client
    - Request types
    - Response types
    - API models
  - Use the generated client for all frontend-to-backend API communication
  - Avoid manually maintaining duplicated API interfaces or types

- **Responsive Design**
  - Fully responsive web interface
  - Automatically resize and adapt the layout based on screen size and device resolution
  - Components, navigation, tables, forms, and dashboards should adjust automatically for different viewport sizes
  - Support:
    - Mobile
    - Tablet
    - Laptop
    - Desktop

## Backend

### 1. Spec

- **Language**
  - TypeScript

- **Runtime / Package Manager**
  - Bun

- **Framework**
  - NestJS

- **REST API**
  - REST API architecture
  - OpenAPI specification
  - Swagger UI for API documentation
  - Automatically generate the OpenAPI schema from NestJS API definitions
  - OpenAPI schema acts as the contract between the backend and frontend

- **OpenAPI TypeScript Compiler**
  - `@hey-api/openapi-ts`
  - Compile the backend OpenAPI specification into a TypeScript REST API client
  - Generate:
    - TypeScript API client
    - Request types
    - Response types
    - Data models
    - API endpoint definitions
  - Generated client is consumed directly by the React frontend
  - Regenerate the client whenever the backend API specification changes
  - Avoid manually maintaining frontend API types

- **Database**
  - PostgreSQL

- **ORM**
  - Prisma

- **Database Migration**
  - Prisma Migrate

- **Redis**
  - Redis for:
    - Cache
    - Temporary data
    - Rate limiting
    - Background task status if needed

- **File Storage**
  - Store uploaded files directly in PostgreSQL
  - Store file binary data using PostgreSQL `BYTEA`
  - Store file metadata such as:
    - File name
    - File type
    - MIME type
    - File size
    - Upload date
    - Related tenant
    - Related property
  - Used for:
    - Rental contracts
    - Tenant documents
    - Receipts
    - Property-related files

- **API Documentation**
  - OpenAPI
  - Swagger UI

- **Containerization**
  - Docker

- **Local Development / Service Management**
  - Docker Compose

- **Docker Compose Services**
  - Frontend
  - Backend
  - PostgreSQL
  - Redis

- **Environment Configuration**
  - `.env`
  - Separate configuration for:
    - Development
    - Staging
    - Production

- **Deployment Architecture**
  - Frontend and backend deployed as separate services
  - PostgreSQL used for:
    - Application data
    - File storage
  - Redis used for cache and temporary data

## API Flow

```text
NestJS Backend
      │
      │ Generate
      ▼
OpenAPI Specification
      │
      │ @hey-api/openapi-ts
      ▼
Generated TypeScript REST API Client
      │
      ├── API Methods
      ├── Request Types
      ├── Response Types
      └── Models
      │
      ▼
React Frontend
```

- Backend owns the API definition.
- NestJS generates the OpenAPI specification.
- `@hey-api/openapi-ts` compiles the OpenAPI specification.
- The generated TypeScript client is used by the React frontend.
- When the backend API changes, regenerate the client instead of manually updating frontend API types.
