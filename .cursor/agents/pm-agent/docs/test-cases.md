# PM Agent validation

## Behavioral cases

| Case | Expected observable result |
| --- | --- |
| New feature, PRD and architecture, missing constitution/spec | Six stages in order, populated plan/checklist/tasks, passed analysis and prepared or evidenced dispatch |
| Existing constitution and matching spec | Both reused byte-for-byte, no generation or branch duplication |
| Existing scaffold constitution/spec | Gap reported; no silent rewrite and no passed gate |
| Multiple matching versions or disagreement with feature metadata | Ask for exact feature before feature mutations |
| PRD disagrees with protected spec | Product question; affected work blocked until a confirmed decision and any specifically requested amendment |
| Clear plan/task technical mismatch | Read-only analyze, separate scoped fix, checklist re-evaluation and reanalysis |
| Dependency cycle or shared parallel file | Validator failure and task correction before delivery |
| Context7 absent | Official-documentation fallback with sources and version evidence |
| All documentation access unavailable | Record verification gap, block decisions requiring it |
| Required Spec Kit skill/helper missing | Identify missing dependency; no imitation or claim of completed stage |
| Coding Agent unavailable | Complete prepared packet with next invocation; no dispatched claim |
| Coding Agent receipt without reply | Dispatched only; no acknowledgment or implementation claim |
| Task progress reported | Preserve IDs/completion evidence, recompute ready set and revalidate snapshots |
| Submitted `/pm-agent` text | Root instruction routes to published skill; host parser/menu support remains separate |
