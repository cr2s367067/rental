# PM Agent requirements

Scope: create a project-local agent and reusable skill; do not run a feature PRD
through planning during agent creation.

| Requirement | Implemented by |
| --- | --- |
| GitHub Spec Kit integration | Six installed skills, scripts and templates, in the requested order |
| Preserve existing constitution | Existence guard, substantive-content check, protected snapshots |
| Preserve matching feature/version specification | Identity resolution, reuse guard, explicit amendment rule |
| PRD and architecture based technical plan | Planning input contract and version-aware research |
| Context7 or online verification | Runtime discovery, official-documentation fallback, research citations |
| Requirements/plan checklist | Quality questions with evidence and recorded gaps |
| Smaller actionable tasks | Concrete deliverables, exact files, acceptance criteria, stable IDs |
| Dependencies, priorities, conflicts and parallelism | Explicit graph and ownership review plus structural validator |
| Analysis and clear technical remediation | Read-only Spec Kit pass, separate authorized corrections, reanalysis |
| Clarification for uncertain product intent | Blocking questions and recorded confirmed decisions |
| Coding Agent context and handoff tracking | Human packet, JSON task metadata, readiness and delivery evidence |
| Reusable invocation | Published pm-agent skill and repository text alias |

Assumptions: current repository is the intended installation scope. No model or
reasoning override was requested; the agent inherits host settings. Coding Agent
identity is resolved on each feature run. The requested `/pm-agent` is supported
as submitted text routing, with `$pm-agent` as the documented native Codex form;
no undocumented slash registration or global configuration is introduced.

Existing scaffold artifacts are not silently treated as adopted project policy.
The current constitution is a template, so future planning must report its gap
and obtain an explicit instruction to complete it before passing that gate.
